# Security policy

This pre-release project does not yet publish supported-version guarantees.
Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private security-advisory feature for the repository. Include affected versions,
reproduction steps, impact, and any suggested mitigation. Maintainers will
acknowledge a complete report and coordinate disclosure when a fix is available.

Never include live financial records, credentials, or other sensitive data in a
report or reproducer.
