Select the cells that hold your data, with the column names in the first row. Select a single cell to use the table it is in, or everything on the sheet. Row numbers in the report are the sheet's own row numbers.

Your cells are read in this window and never sent anywhere. This pane loads Microsoft's Office library to talk to Excel.

Diagnostics for testers

Runs the checklist from the add-in's real-Excel test: environment, security policy, network use, reading and checking a large generated book, writing the results sheet, saving and loading checks, and confirming your data was not changed. It creates a sheet named "finassert spike data" (replaced if it exists) and nothing else in your workbook. Use a new, empty workbook.
