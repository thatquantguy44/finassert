## Review focus

- Closeness is abs(a-e) <= absolute + relative * max(abs(a), abs(e)).
- Tolerance components are finite and nonnegative; booleans are not supported numeric
  scalars.
- Decimal operands never convert to binary float; non-finite operands never compare
  close.

Unresolved implementation gaps and contract decisions are tracked in
[tasks.md](tasks.md). Changes to outcomes, IDs, tolerance mathematics, serialization, or
row identity require a spec amendment and migration note.
