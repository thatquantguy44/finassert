# 0018 — Roadmap

## Current

Local single-user reference reader and pinned, scoped API. The supplied local
checkout is the default; a local owner may explicitly select the pinned GitHub
source. It is optional and does not change workbook validation.

## Next

Native Mac Excel inspection of the reference panel alongside 0016 E-06.

## Later

An authenticated multiuser HTTPS service, if shared access is requested.
Full-text search and document rendering are separate, optional improvements.
